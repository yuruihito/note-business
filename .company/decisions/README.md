# 意思決定ログについて

このディレクトリには、CEOの意思決定を月別ファイル（例: `2026-08.md`）として記録する。

## 記録するタイミング

- `/ai-ceo:approve` / `/ai-ceo:reject` が実行されたとき
- CEOが戦略的な判断（新規事業の開始、方針転換など）を下したとき

## フォーマット例

```
## 2026-08-07
- [AQ-003] 承認: 新商品LPの公開（CMO） -- 理由: 訴求内容が既存ブランドと一致
- 方針決定: 〇〇プロダクトの開発を一時停止し、△△に集中する
```

Orchestratorは承認/却下のたびに、当月ファイルへ追記する。
